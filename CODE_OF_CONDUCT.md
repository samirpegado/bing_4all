# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) spirit: be respectful, assume good intent, and focus on constructive collaboration.

## Our standards

Examples of behavior that contributes to a positive environment:
- using welcoming and inclusive language
- being respectful of differing viewpoints
- gracefully accepting constructive criticism
- focusing on what is best for the community

Examples of unacceptable behavior:
- harassment, trolling, or personal attacks
- publishing others’ private information
- other conduct which could reasonably be considered inappropriate

## Enforcement

Report unacceptable behavior to the maintainers (GitHub Security Advisories / private contact on the maintainer profile). Maintainers may remove contributions or ban participants who violate these standards.

## Scope

This Code of Conduct applies within project spaces and when an individual is representing the project in public spaces.
